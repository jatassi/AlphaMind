# 04d — Frontend foundation

## Goal

Stand up the TypeScript + React + Vite frontend subtree under `command_center/frontend/` **on top of the lint + formatter foundation already landed by story 04c**: Vite + TanStack Router/Query/Table integration, Shadcn/UI primitives, Tailwind CSS, WebAuthn registration + login UI hitting the routes from story 03, OpenAPI type generation against the FastAPI app's reflected schema, shared API client + EventSource hook, and FastAPI `StaticFiles` mount serving the built `dist/`. Toolchain is **bun** (per [ALP-128](https://linear.app/alphamind-jatassi/issue/ALP-128/command-center) § Pre-resolved (J) / (N)). Every `.ts` / `.tsx` file added here must pass `bun run lint` + `bun run format:check` (the config files land in 04c). Subsequent view stories (05b–05j, 06a–06c) add per-view route + component code on top of this foundation.

Wants Opus despite the mechanical-feeling scaffolding surface — the TanStack Router shape + auth flow integration + the EventSource hook for the multiplexed `/api/events` stream are design-heavy decisions that ripple across every view story.

### 3\. Vite config

`vite.config.ts` sets up:

* React plugin.
* Path alias `@/` → `src/`.
* Dev proxy: `/api/*`, `/auth/*`, `/events`, `/healthz` → `http://127.0.0.1:8080` (the FastAPI backend).
* `build.outDir = "dist"`.

### 4\. TanStack Router shape

`routes/__root.tsx` — outermost layout: navigation shell + `<Outlet />`. `routes/_authed.tsx` — protected layout that calls a `useSession()` hook (querying `/auth/me` or equivalent — add a thin endpoint in this story if absent) and redirects to `/login` on 401. View stories add routes as children of `_authed/` (e.g., `_authed/live.tsx`, `_authed/history.tsx`).

### 5\. WebAuthn UI (`auth/`)

`webauthn.ts` — converts between `py_webauthn`'s base64url JSON envelopes and the browser's `PublicKeyCredentialCreationOptions` / `PublicKeyCredentialRequestOptions` shapes. `register.tsx` — handles first-launch setup-token entry + `navigator.credentials.create()` + POST to `/auth/register/complete`. `login.tsx` — `navigator.credentials.get()` + POST to `/auth/login/complete`.

### 6\. API client + EventSource hook (`api/`)

`client.ts` — typed `fetch` wrapper. Auto-injects `X-CSRF-Token` header on POST/PUT/PATCH/DELETE (read from `cc_csrf` cookie via `document.cookie` parser). On 401, redirects to `/login`. On 403, surfaces a toast for CSRF mismatch.

`events.ts` — `useEventStream()` React hook wrapping `EventSource('/api/events')` with auto-reconnect on close and a typed dispatcher: subscribers register interest by `<source>:<event_name>` (e.g. `pipeline:invocation_started`); the hook fans events to interested subscribers. Slow-consumer protection: per-subscriber queue capped at N events; overflow drops oldest with a warning toast.

`openapi.d.ts` — generated by `bunx openapi-typescript http://127.0.0.1:8080/openapi.json -o src/api/openapi.d.ts`. Generation happens at build time (a `package.json` script `generate-types`); the generated file is committed for repeatable builds.

### 7\. FastAPI static mount

Extend `command_center/app.py` (from [ALP-666](https://linear.app/alphamind-jatassi/issue/ALP-666/02-command-center-backend-foundation)) to mount `StaticFiles(directory=config.frontend.dist_path, html=True)` at `/` *after* all `/api/*` and `/auth/*` and `/events` routes are registered. In dev mode (detected via env var or config flag), skip the mount — browser hits Vite directly + Vite proxies to FastAPI.

### 8\. Smoke test

`frontend/src/__tests__/smoke.test.tsx` — Vitest test rendering `<App />` against a mocked session; asserts the nav renders + the login page mounts at `/login`.

### 9\. Lint conformance from day one
